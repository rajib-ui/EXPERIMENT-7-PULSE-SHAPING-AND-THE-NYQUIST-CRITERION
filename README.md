# EXPERIMENT-7-PULSE-SHAPING-AND-THE-NYQUIST-CRITERION


This experiment demonstrates pulse shaping and the Nyquist zero-ISI criterion using Python in Google Colab.

Topics Covered
Rectangular, sinc, Raised-Cosine (RC) and Root-Raised-Cosine (RRC) pulses
Effect of roll-off factor \(\alpha = 0, 0.25, 0.5, 1\)
Time and frequency responses
Nyquist zero-crossing verification
RRC transmitter and receiver cascade
Bandwidth versus roll-off factor
Tools
Python
Google Colab
NumPy
Matplotlib
